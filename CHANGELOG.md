# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-10

### Added
- Initial UDL (User Defined Language) for Svelte 5
- Dark theme (`Svelte.xml`) — VSCode Dark+ inspired
- Light theme (`Svelte-Light.xml`) — VSCode Light+ inspired
- Code folding for Svelte block syntax (`{#if}`, `{#each}`, `{#await}`, `{#key}`, `{#snippet}`)
- Highlighting for Svelte 5 runes (`$state`, `$derived`, `$effect`, `$props`, `$bindable`, `$inspect`, `$host`)
- Highlighting for special tags (`{@render}`, `{@html}`, `{@const}`, `{@debug}`, `{@attach}`)
- Highlighting for directives (`bind:`, `on:`, `use:`, `transition:`, `class:`, `style:`)
- Autocomplete file with Svelte runes and block syntax
- PowerShell installer + uninstaller
- Sample `.svelte` files for testing
- XML validation script
- Documentation: README, INSTALL, ROADMAP
